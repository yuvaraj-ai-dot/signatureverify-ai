# SignatureVerify AI — Prototype

A standalone browser-based prototype for an AI-assisted signature comparison workflow.

## Run
Open `index.html` in a modern browser.

## Included
- Dashboard
- New Verification workflow
- Reference Signature Library
- Verification Results
- Match / Review / Mismatch concept
- Verification History / Audit Trail
- Reports
- Administration

## Important
This is a UI/workflow prototype. It does not perform a real forensic signature determination or connect to a production AI model/database. Production implementation should add validated signature-comparison technology, secure storage, access controls, audit logging, and appropriate human review.
